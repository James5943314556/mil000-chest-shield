# @mil000 Chest Shield

Chrome extension that covers `@mil000` tweets on X with a Fortnite-style chest.

## Install

1. Download this repo as a ZIP or clone it.
2. Open `chrome://extensions`.
3. Turn on Developer mode.
4. Click Load unpacked.
5. Select this folder.
6. Refresh `https://x.com`.

## Behavior

- Covers `@mil000` tweets on For You and other timelines.
- Covers posts, quote tweets, reposts, and replies on `https://x.com/mil000`.
- Plays the chest sound on hover.
- Click the chest to reveal the tweet and play the Fahhhh sound.
